## FULLSTACK DEVELOPER PRACTICAL TEST

## Ketentuan Umum

- Teknologi: Flutter (Diutamakan), JavaScript, MySQL, dan Git.

- Gunakan REST API untuk komunikasi frontend dan backend, dokumentasi menjadi nilai tambah

- Terapkan validasi form, validasi backend, dan relasi database yang sesuai.

- Sertakan README, struktur database, dan petunjuk menjalankan aplikasi.

- Push source code ke repository GitHub dan kirimkan tautan repository kepada recruiter.

- Tersedia 4 pilihan studi kasus. Kandidat diwajibkan memilih dan mengerjakan salah satu studi kasus sesuai minat dan pemahaman masing-masing.

- Batas pengumpulan 1x24 jam setelah test ini diterima.

## Studi Kasus 1 — Hasil Produksi dan Gudang

- Master barang.

- Transaksi hasil produksi barang.

- Transaksi Penerimaan barang.

- Status Hasil Produksi, Penerimaan, Stok barang.

## Studi Kasus 2 — Mutasi Stok Antar Gudang

- Master barang.

- Master Gudang dan Stok Per gudang.

- Transaksi mutasi barang.

- Riwayat mutasi.

## Studi Kasus 3 — Pembelian dan Penerimaan barang

- Master barang.

- Transaksi Pembelian.

- Transaksi Penerimaan.

- Status Pembelian, Penerimaan, Stok

## Studi Kasus 4 — Transaksi Bahan Baku

- Master bahan baku.

- Transaksi barang keluar.

- Transaksi pengembalian barang.

- Daftar stok terkini dan riwayat transaksi.

## Ketentuan Penilaian

- Ketepatan alur bisnis dan relasi database.

- Fundamental JavaScript dan Flutter.

- Komunikasi data melalui REST API.

- Validasi form dan penanganan error.

- Konsistensi data dan perhitungan stok.

- Kualitas struktur kode dan penggunaan Git.
